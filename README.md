# To-Do List

## 1. Description

A to-do list web app built with vanilla HTML, CSS and JavaScript.

## 2. Technologies and Versions

- HTML5, CSS3, vanilla JavaScript (no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/To-Do-list.git
cd To-Do-list
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- Add and manage tasks in a simple list UI (`index.html`, `style.css`, `script.js`), with image assets under `images/`.

## 7. Screenshots / Demo

No live demo; open `index.html` locally.

## 8. Running Tests

No automated tests in this repo.
